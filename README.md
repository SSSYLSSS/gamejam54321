# 五!四!三!二十一点!

> 聚光灯48小时GameJam广州站2026 参赛作品

一款以 **21点** 为基础的策略卡牌对战游戏。玩家与对手（AI 或真人）对战，通过抽牌、弃牌、保留等策略操作，配合丰富的特殊牌效果，让手牌点数尽可能接近 21 点而不爆。

## 游戏规则

### 胜负条件

一轮比赛共 5 场对弈，**先胜 3 场**者获胜。

每场对弈中：
- 总点数超过 21 点即为「爆点」
- 仅一方爆点 → 未爆方直接获胜
- 双方均未爆 → 更接近 21 点者胜
- 双方均爆点 → 爆得少的赢
- 点数相同 → 平局

### 回合流程

每场对弈分为 **抽牌阶段** 和 **结算后阶段**：

| 阶段 | 说明 |
|------|------|
| **五!** | 双方各抽 5 张手牌，可选至多 5 张弃置后重新抽取 |
| **四!** | 可选至多 4 张弃置后重新抽取 |
| **三!** | 可选至多 3 张弃置后重新抽取 |
| **结算** | 逐张翻开对方手牌，触发特殊效果，比较双方点数 |
| **二!** | 选至多 2 张手牌放回自己的抽牌堆（下局可能再抽到） |
| **一!** | 选至多 1 张手牌保留至下一局（下局开始直接在手中） |

### 牌库系统

- 使用标准 **54 张牌**（含大小王）
- 双方各拥有独立的抽牌堆和弃牌堆
- 弃牌堆耗尽后洗牌重新构成抽牌堆
- 下一场对弈继承上一局结束时的牌库状态

### 牌的分类

| 类型 | 包含 | 标识颜色 |
|------|------|----------|
| 普通牌 | 2, 3, 4, 5, 6, 7 | 白色 |
| 稀有牌 | 8, 9, 10 | 紫色 |
| 罕见牌 | J, Q, K | 金色 |
| A | A | 红色 |
| 鬼牌 | 小王, 大王 | 彩虹 |

### 特殊牌效果

#### 普通牌

| 牌 | 效果 |
|----|------|
| **2~6** | 无特殊效果，点数即面值 |
| **7** | 不可被任何效果改变点数或删除；3 张 7 触发特殊胜负规则 |

#### 稀有牌

| 牌 | 效果 |
|----|------|
| **8** | 结算时己方所有普通牌各 -2 点，对方所有普通牌各 +2 点（可叠加） |
| **9** | 灵活牌：点数可视为 0 或 9（自动选择更优值） |
| **10** | 结算时己方每张稀有牌和罕见牌点数 -9（可叠加） |

#### 罕见牌

| 牌 | 效果 |
|----|------|
| **J** | 结算时己方所有普通牌点数变为 0 |
| **Q** | 结算时对方最高普通牌点数 ×2，己方点数取至十位（可叠加） |
| **K** | 结算时对方普通牌和稀有牌点数 ×2（可叠加） |
| **A** | 结算时对方同花色牌点数 ×2（可叠加） |

#### 鬼牌

| 牌 | 效果 |
|----|------|
| **小王** | 抽牌阶段结束后触发：选择 0~13 作为小王自身点数 |
| **大王** | 抽牌阶段结束后触发：选一张手牌设为任意点数(0~13)，大王自身也选任意点数(0~13)，仅当局生效 |

> 鬼牌效果触发后仍保留在手中，以选定点数计入总分。

### 结算顺序

效果按以下顺序依次结算：

1. **基础点数** — 各牌面值之和
2. **加减效果** — 8: 己方普通牌 -2，对方普通牌 +2
3. **乘算效果** — J: 普通牌→0，K: 对方普通+稀有牌 ×2，A: 对方同花色 ×2
4. **最终修正** — 10: 己方稀有/罕见牌各 -9
5. **Q 效果** — 对方最高普通牌 ×2，己方取整至十位

9 的灵活选择在全部计算完成后自动优化。

## 游戏特色

- **深度策略** — 弃牌、保留、放回牌堆，每一步都影响后续对局
- **丰富效果** — 14 种特殊牌效果相互配合，组合玩法多样
- **跨局博弈** — 牌库状态跨局继承，长线策略至关重要
- **在线对战** — 支持多人匹配对战
- **像素美术** — 全局像素渲染风格，复古精致
- **光效粒子** — 翻牌光线连接、胜利金色粒子、技能飘字提示

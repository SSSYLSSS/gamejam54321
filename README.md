# 五!四!三!二十一点!

一款改版 21 点卡牌对战博弈游戏，带有 NanoVG 粒子特效和动态背景。

## 游戏规则

### 基本规则
- **5局3胜**，双方各有 54 张牌的独立抽牌堆
- 每局发 5 张手牌，经过 3 回合弃牌换牌后结算
- 结算时比较谁更接近 21 点（绝对值距离，越近越好）

### 回合流程
| 阶段 | 说明 |
|------|------|
| **五!** | 第一回合：可弃置至多 5 张牌，再抽 5 张 |
| **四!** | 第二回合：可弃置至多 4 张牌，再抽 4 张 |
| **三!** | 第三回合：可弃置至多 3 张牌，再抽 3 张 |
| 结算 | 比较双方手牌点数与 21 点的距离 |
| **二!** | 结算后：弃置至多 2 张至自己抽牌堆 |
| **一!** | 结算后：保留至多 1 张至下局手牌 |

### 卡牌点数
- **A** = 1 点, **2~10** = 面值, **J** = 11 点, **Q** = 12 点, **K** = 13 点
- **鬼牌** = 结算时可选 0~13 点

### 卡牌特效
| 牌面 | 基础点数 | 效果 |
|------|---------|------|
| **A** | 1 | 结算时翻倍对方同花色牌的点数 |
| 2~6 | 面值 | 普通牌，无特效 |
| **7** | 7 | 点数不可被修改/删除；拥有 3 张 7 触发特殊胜负规则 |
| **8** | 8 | 使自己的普通牌 (2~6) 点数各减 1 |
| **9** | 0 或 9 | 结算时自动选择最优点数（0 或 9） |
| **10** | 10 | 若弃置过 10，最终点数 +1 |
| **J** | 11 | 弃置时从弃牌堆抽牌；结算时翻倍对方普通牌(2~6) |
| **Q** | 12 | 结算时使对方点数最小的非免疫牌变为 0 |
| **K** | 13 | 手中每张 K 最终点数额外 +1 |
| **小王** | 可选 0~13 | 结算前移除对方一张牌 |
| **大王** | 可选 0~13 | 可将自己一张牌视为任意点数 |

### 结算优先级
1. 对方 J 效果 → 翻倍我方普通牌
2. 对方 Q 效果 → 我方最小牌变 0
3. 对方 A 效果 → 翻倍我方同花色牌
4. 自己 8 效果 → 自己普通牌 -1
5. 7 免疫 → 点数不受任何影响
6. 9 灵活优化 → 超过 21 时自动选 0
7. K 加成 → 每张 K 额外 +1
8. 10 加成 → 每张弃置过的 10 额外 +1

## 项目结构

```
scripts/
├── main.lua                    # 主入口 (3D场景 + VFX + UI初始化)
├── core/                       # 核心数据层
│   ├── Card.lua                # 卡牌数据与工具函数
│   ├── Constant.lua            # 枚举常量定义
│   ├── GameConfig.lua          # 游戏配置参数
│   └── Deck.lua                # 牌堆管理
├── model/                      # 数据模型
│   ├── GameState.lua           # 全局游戏状态
│   ├── PlayerState.lua         # 玩家状态 (手牌/弃牌追踪)
│   └── RoundState.lua          # 单局状态 (弃牌堆/回合计数)
├── system/                     # 逻辑系统
│   ├── AISystem.lua            # AI决策系统
│   ├── DeckSystem.lua          # 牌堆操作
│   ├── EffectSystem.lua        # 卡牌效果执行
│   ├── PhaseManager.lua        # 阶段流转管理
│   └── RuleEngine.lua          # 规则引擎 (结算/胜负判定)
├── service/                    # 服务层
│   └── GameController.lua      # 游戏控制器 (对外接口)
├── ui/                         # UI 层
│   ├── Colors.lua              # 全局颜色定义
│   ├── components/
│   │   └── CardWidget.lua      # 卡牌UI组件 (3倍大+悬停放大+效果提示)
│   └── scenes/
│       ├── MenuScene.lua       # 主菜单
│       ├── GameScene.lua       # 游戏界面
│       └── SettingsScene.lua   # 设置界面
└── vfx/                        # 视觉特效层
    ├── VFXConfig.lua           # VFX参数配置
    ├── VFXManager.lua          # VFX统一管理器
    ├── ParticleSystem.lua      # NanoVG粒子系统
    ├── BackgroundRenderer.lua  # 动态背景 (星空+光带+暗角)
    └── CardGlow.lua            # 卡牌发光效果
```

## 视觉特效

- **动态背景**: 深色渐变底色 + 流动光带 + 闪烁星星
- **NanoVG 暗角**: 屏幕边缘渐变变暗
- **粒子效果**: 胜利金色烟花 / 失败暗红碎裂 / 弃牌蓝色飞散 / J效果紫色闪光
- **卡牌光晕**: 特殊卡牌呼吸发光 (鬼牌紫 / J蓝紫 / 7绿 / A金 / Q粉 / K红)
- **呼吸动画**: 光晕 shadowBlur 与 alpha 随正弦波脉动（周期约 2.1 秒，范围 0.6~1.0）

## 技术栈

- **引擎**: UrhoX (TapTap Spark Editor)
- **语言**: Lua 5.4
- **UI**: urhox-libs/UI (Yoga Flexbox 布局)
- **特效**: NanoVG 矢量图形 + HDR Bloom 模拟
- **后处理**: 3D Scene + DarkNight LightGroup

## 开发

项目基于 TapTap Maker 在线 IDE 开发，使用 `mcp__sce-urhox__build` 构建。

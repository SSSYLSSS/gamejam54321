# 五\!四\!三\!二十一点\!

一款改版21点卡牌对战博弈游戏。

## 规则简介

- **5局3胜**，双方各有54张牌的独立抽牌堆
- 每局发5张手牌，经过3回合弃牌换牌后结算
- **第一回合(五\!)**: 可弃置至多5张牌再抽5张
- **第二回合(四\!)**: 可弃置至多4张牌再抽4张
- **第三回合(三\!)**: 可弃置至多3张牌再抽3张
- 结算时比较谁更接近21点(绝对值距离)
- 结算后: 弃置至多2张至牌堆**(二\!)**，保留至多1张至下局**(一\!)**

## 卡牌特效

| 牌面 | 效果 |
|------|------|
| A | 结算时翻倍对方同花色牌点数 |
| 2~6 | 普通牌，无特效 |
| 7 | 不可弃置/修改；拥有3张7触发特殊胜负规则 |
| 8 | 使自己的普通牌(2~6)点数各减1 |
| J | 弃置时可从弃牌堆抽一张牌 |
| 小王 | 点数可选0~13，结算前移除对方一张牌 |
| 大王 | 点数可选0~13，可将自己一张牌视为任意点数 |

## 项目结构

```
scripts/
├── main.lua         # 主入口 - UI界面和游戏流程控制
├── CardDefs.lua     # 卡牌定义 - 花色、点数、创建/洗牌工具
├── GameLogic.lua    # 游戏逻辑 - 回合管理、结算、特效计算
└── AIPlayer.lua     # AI决策 - 弃牌策略、鬼牌效果选择
```

## 技术栈

- UrhoX 游戏引擎
- Lua 5.4
- urhox-libs/UI 组件库 (Yoga Flexbox 布局)

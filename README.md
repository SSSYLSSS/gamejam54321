# 54321 - 策略卡牌对战游戏

一款以 **21点** 为核心的策略卡牌游戏，玩家与 AI 对战，通过巧妙的抽牌、弃牌和特殊牌效果来获得更接近 21 点的手牌组合。

## 游戏规则

### 基本目标

**先赢 3 局**的一方获胜。每局中，双方手牌点数更接近 **21 点**的一方赢得该局。

### 游戏流程

每局分为以下阶段：

| 阶段 | 名称 | 说明 |
|------|------|------|
| 五! | 第一回合 | 双方从牌库抽满5张手牌，可选择弃置至多5张 |
| 四! | 第二回合 | 再次补满手牌，可弃置至多4张 |
| 三! | 第三回合 | 再次补满手牌，可弃置至多3张 |
| 结算 | 翻牌结算 | 逐张翻开AI手牌，比较双方点数 |
| 二! | 放回抽牌堆 | 选择至多2张牌放回自己的抽牌堆 |
| 一! | 保留至下局 | 选择至多1张牌保留到下一局使用 |

### 特殊牌效果

| 牌 | 效果 |
|----|------|
| **A** | 结算时翻倍对方同花色牌的点数 |
| **2~6** | 普通牌，点数即面值 |
| **7** | 不可被改变点数/删除；3张7触发特殊胜负规则 |
| **8** | 使自己普通牌(2~6)点数各减1 |
| **9** | 结算时点数可视为0或9（自动选择更优） |
| **10** | 若弃置过此牌，最终点数+1 |
| **J** | 弃置时从弃牌堆抽牌；结算前翻倍对方普通牌点数 |
| **Q** | 结算时使对方点数最小的牌变为0 |
| **K** | 对方最终点数向上取整，己方最终点数-5后向下取整 |
| **小王** | 点数可选0~13，移除对方一张牌 |
| **大王** | 点数可选0~13，可将自己一张牌视为任意点数 |

### 三7特殊规则

当一方手牌中有 **3张或以上的7** 时，触发特殊胜负判定（无需常规点数比较）。

### 牌库系统

- 使用标准 **54张牌**（含大小王）
- 每位玩家拥有独立的 **抽牌堆** 和 **弃牌堆**
- 弃牌堆洗牌后会重新成为抽牌堆

## 项目结构

```
scripts/
├── main.lua              # 入口文件
├── core/                 # 核心定义
│   ├── Card.lua          # 卡牌数据模型
│   ├── Constant.lua      # 游戏常量与枚举
│   └── GameConfig.lua    # 可配置参数
├── model/                # 数据模型
│   ├── GameState.lua     # 游戏全局状态
│   ├── PlayerState.lua   # 玩家状态（牌库/弃牌/手牌）
│   └── RoundState.lua    # 单局回合状态
├── service/              # 业务逻辑
│   └── GameController.lua # 游戏控制器（状态机驱动）
├── system/               # 游戏系统
│   ├── AISystem.lua      # AI 决策逻辑
│   ├── DeckSystem.lua    # 牌库管理（洗牌/发牌）
│   ├── EffectSystem.lua  # 特殊牌效果处理
│   ├── PhaseManager.lua  # 阶段流转管理
│   └── RuleEngine.lua    # 规则引擎（点数计算/结算）
├── ui/                   # 用户界面
│   ├── Colors.lua        # 配色方案
│   ├── components/       # UI 组件
│   │   └── CardWidget.lua # 卡牌渲染组件
│   └── scenes/           # 场景
│       ├── GameScene.lua  # 游戏主场景
│       ├── MenuScene.lua  # 主菜单
│       └── SettingsScene.lua # 设置页面
└── vfx/                  # 视觉特效
    ├── BackgroundRenderer.lua # 背景渲染
    ├── CardGlow.lua       # 卡牌光晕效果
    ├── ParticleSystem.lua # 粒子系统
    ├── VFXConfig.lua      # 特效配置
    └── VFXManager.lua     # 特效管理器
```

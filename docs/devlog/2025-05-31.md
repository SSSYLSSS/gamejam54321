# 开发日记 - 2025/05/31

## 今日改动总览

### 1. 星星粒子特效

- 新增 5 张星星粒子素材（`assets/pic/stars/Star1~5.png`）
- 粒子系统支持随机散布星星图片粒子（40% 概率），带旋转动画
- 星星粒子使用最近邻过滤（Nearest），保持像素风格清晰
- 星星粒子尺寸为普通粒子的 3.6 倍

### 2. 粒子效果统一

- 胜利/失败粒子参数统一（数量 40、速度 400、存活 2s、半径 6），仅颜色不同
  - 胜利：金色 `(1.0, 0.85, 0.2)`
  - 失败：红色 `(0.8, 0.2, 0.2)`

### 3. 王牌点数标记

- 使用大王/小王设定点数时，在牌面右上角显示金色圆形标记
- 标记区分 AI 牌（小尺寸 28px）和玩家牌（大尺寸 44px）
- 支持 `jokerOverride`（大王赋予其他牌）和 `jokerValue`（王自身点数）两种情况

### 4. Bug 修复

- **提示词消失**：修复结算后 middleArea 不再显示的问题，在关闭结算遮罩时恢复透明度
- **AI 小王 Bug**：修复对方有小王时结算动画期间牌被错误删除的问题（Refresh 覆盖 displayHand）
- **标题图片遮挡按钮**：给菜单标题图片添加 `pointerEvents = "none"`，防止缩放时挡住"开始游戏"

### 5. UI 微调

- 中间提示词字体增大两号（phaseLabel 15→17, infoLabel 13→15, pointsLabel 14→16）

## 技术备注

- `nvgCreateImage(ctx, path, 32)` — flag 32 即 `NVG_IMAGE_NEAREST`（1<<5），像素风必备
- `nvgImagePattern` + `nvgSave/Translate/Rotate/Restore` 实现带旋转的图片粒子
- 结算动画期间用 `if settlementAnim then return end` 守卫 Refresh 函数，避免逻辑手牌覆盖动画展示
